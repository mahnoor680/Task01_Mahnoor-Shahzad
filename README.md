# Task01_Mahnoor-Shahzad

## 📌 Project Description

This project is my **Task 1 submission for the DecodesLabs Front-End Development Internship**.

The objective of this task was to create a webpage using **semantic HTML5 tags** and **CSS styling**. The website presents my profile, skills, projects, achievements, testimonials, and contact details in a clean and organized layout.

---

## ✨ Features

- ✅ Semantic HTML5 structure
- ✅ Responsive portfolio layout
- ✅ Fixed navigation bar with smooth scrolling
- ✅ About Me section
- ✅ Technical skills showcase
- ✅ Portfolio projects with live demo links
- ✅ Achievements/certificates section
- ✅ Testimonials section
- ✅ Contact form section
- ✅ Social media integration
- ✅ CSS animations and hover effects

---

## 🛠️ Technologies Used

- HTML5

- Google Fonts
- Flexbox
- CSS Grid
